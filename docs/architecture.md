## Project Architecture and Design Notes


**Design Philosophy (Single Page Focus):** All critical Key Performance Indicators (KPIs) and metrics must be consolidated onto a single, long, scrollable report page. This design prioritizes information density and readability over extensive navigation.

**Data Model:** The data model is based on the separation of Fact tables (e.g., Rides) and Dimension tables (e.g., Locations).

**Goal:** To ensure that all core performance indicators are immediately visible upon loading, requiring minimal user interaction.
**Overall Vision:** The goal of this project is to create a highly focused, executive-level Power BI dashboard.
