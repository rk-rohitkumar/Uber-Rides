# Analysis response format

When the user asks for analysis, review, takeover guidance, or project understanding, structure the response in this order:

1. Current understanding
2. Key findings
3. Gaps / risks / ambiguities
4. Recommended next steps
5. Files that should be reviewed or updated next

When the user asks for a plan:
- Provide ordered steps.
- Separate immediate validation, medium-priority cleanup, and longer-term improvement opportunities.

When the user asks for edits:
- State the target files first.
- Then apply the smallest safe set of changes.
