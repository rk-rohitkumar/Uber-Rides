# Report Visual Dictionary\n\nThis document serves as a centralized catalog for all visuals in the Power BI report, ensuring consistency and traceability.\n\n## Overview\nAll visuals are designed under the constraint of **Single-Page Consolidation**.
\n## Visual Definitions\nVisual definitions are stored in JSON files located within `PBIP/Uber Rides.Report/definition/pages/*/visuals/*.json`.\n\n## Template for Each Visual\nFor each visual, please document the following:\n1. **Visual Name:** (Name displayed on the report)\n2. **Source File:** (Path to the defining JSON file)\n3. **Business Objective:** The specific business question this visual answers.\n4. **Core Measures Used:** List all measures from `Measures_Reference.md` used in this visual.\n5. **Data Context:** Identify which Dimension tables are referenced for context (e.g., Location, Date).\n\n## Example Entry\n*Example: Main Page Overview Visual*\n- **Visual Name:** Total Ride Summary\n- **Source File:** `PBIP/Uber Rides.Report/definition/pages/f58998c2239001be45dc/visuals/...'\n- **Business Objective:** To provide a high-level, consolidated view of all ride activity for the selected period.\n- **Core Measures Used:** Total Bookings, Booking Value, Completion Rate.\n- **Data Context:** Locations (for regional context), Date Table (for time series).\n
